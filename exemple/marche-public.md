# Page “Marchés publics” (hub)

---

### Rôle & objectifs

- **Rôle** : page d’entrée dédiée pour **marchés publics / propriétaires publics** → rassurer + prouver + simplifier la prise de contact.
- **Objectif UX** : répondre vite à “Qui / quoi / où / garanties / références / comment vous consulter ?” (logique “confiance immédiate”).
- **CTA principal** : **“Contacter pour marché public”** (ou “Demander une réponse / un chiffrage”)
- **CTA secondaires** : “Voir les références”, “Télécharger / demander les justificatifs”, “Appeler” (mobile).

### SEO (cadrage)

- **URL** : `/marches-publics/`
- **H1** (format) : “Travaux de plâtrerie, isolation & finitions — Marchés publics — Strasbourg / Alsace”
- **Schema** à prévoir : `LocalBusiness / ProfessionalService`, `Service`, `Review`, `FAQPage` (si FAQ).

---

## Carcasse (sections dans l’ordre)

> Priorité : Indispensable / Recommandé / Optionnel
> 

### 1) Hero “Acheteurs publics”

**Objectif** : qualifier la cible + rassurer instantanément + pousser au contact.

- **Contenus attendus**
    - Titre (qui/quois/où)
    - Sous-titre : prestations clés + zone
    - **Preuves instantanées** (logos RGE + décennale/RC Pro)
    - CTA principal + CTA “Appeler” (mobile sticky)
- **Questions traitées**
    - “Intervenez-vous sur bâtiments/locaux publics en site occupé ?”
    - “Êtes-vous assurés / certifiés (RGE) ?”
    - “Intervenez-vous bien sur Strasbourg/Alsace ?”
        
        **Priorité : Indispensable**
        

---

### 2) Bloc “Prestations compatibles marché public”

**Objectif** : cadrer le périmètre + éviter les demandes hors-scope.

- **Format recommandé** : 4–6 cartes (Plâtrerie/faux plafonds, Isolation thermique/phonique, Enduits, Peinture & lissage, Rénovation intérieure “lot finitions”).
- **Pour chaque carte**
    - Ce qu’on fait (liste courte)
    - Types de sites concernés (écoles, bureaux, parties communes, logements gérés…) *(à valider si tu veux être ultra spécifique)*
    - Lien vers page service correspondante
- **CTA** : “Demander un chiffrage”
    
    **Priorité : Indispensable**
    

---

### 3) Preuves “Références secteur public”

**Objectif** : “preuve par l’image” + crédibilité immédiate pour acheteurs publics.

- **Contenus attendus**
    - 3–6 vignettes “références” (avant/après si possible)
    - Pour chaque : type de site, ville/quartier, type de travaux, durée indicative
    - Filtre/Tag “Secteur public” (même si c’est juste un filtre UX dans le portfolio)
- **CTA** : “Voir toutes les références”
- **Objections traitées**
    - “Avez-vous déjà fait des chantiers comparables ?”
    - “Pouvez-vous prouver la qualité de finition ?”
        
        **Priorité : Indispensable**
        

---

### 4) “Méthode & organisation chantier”

**Objectif** : vendre la fiabilité (délais, propreté, coordination), point critique pour public/propriétaires publics.

- **Contenus attendus**
    - Frise / étapes : Contact → Visite → Devis → Planification → Travaux → Réception
    - Engagements opérationnels (liste) :
        - respect planning / jalons
        - protection & propreté
        - communication (interlocuteur unique)
        - gestion des nuisances (site occupé) *(si vrai, sinon formulation prudente)*
- **Preuves** : 1 mini-cas (photo + 3 bullets “contexte / contrainte / résultat”)
    
    **Priorité : Recommandé (mais très fort pour ta cible)**
    

---

### 5) “Conformité, garanties, certifications”

**Objectif** : faciliter le “go/no-go” administratif.

- **Contenus attendus**
    - Bloc logos + phrases courtes : **Certifié RGE**, assurance décennale, RC Pro
    - “Justificatifs disponibles” : **bouton** “Demander les documents” (plutôt que téléchargement public si tu veux contrôler)
    - (Option) mention de l’assureur / références (tu as APRIL + n° police, à afficher si souhaité)
- **Objections traitées**
    - “Vos assurances/certifs sont-elles à jour ?”
    - “Pouvez-vous fournir les pièces ?”
        
        **Priorité : Indispensable**
        

---

### 6) “Capacités & zone d’intervention”

**Objectif** : réduire l’incertitude (où / types de chantiers / taille).

- **Contenus attendus**
    - Zone : Strasbourg + alentours / Alsace (carte ou liste de communes)
    - Types de chantiers : petits et gros (si maintenu)
    - Délais : formulation non-risquée (“dépend du chantier, engagement sur planning validé”)
        
        **Priorité : Recommandé**
        

---

### 7) Bloc “Aides & RGE” (uniquement informatif)

**Objectif** : répondre aux questions récurrentes sans promettre d’accompagnement.

- **Contenus attendus**
    - Micro-bloc “À quoi sert le RGE ?”
    - Liste courte des dispositifs (MaPrimeRénov’, CEE, éco-PTZ) **+ phrase claire** : “Nous informons sur les principes ; les démarches se font via les organismes/plateformes dédiés.”
        
        **Priorité : Optionnel** (utile surtout si propriétaires publics = parc de logements)
        

---

### 8) FAQ “Marchés publics”

**Objectif** : lever les objections finales + aider le SEO via FAQPage.

- **Questions types (à adapter)**
    - Délais de réponse devis ? (ex : 24–48h si vous le tenez)
    - Intervention en site occupé / contraintes horaires ?
    - Gestion de la propreté / protection ?
    - Garanties & documents fournis ?
    - Zone d’intervention exacte ?
    - “Faites-vous aussi des petits chantiers ?”
        
        **Priorité : Recommandé**
        

---

### 9) CTA final “Contact marchés publics”

**Objectif** : conversion (sans friction).

- **Contenus attendus**
    - 2 choix : **Formulaire court** + coordonnées directes
    - Champs recommandés (4–6 max) : Organisme / Nom / Téléphone / Email / Type de travaux / Lieu / Message
    - “Appeler” cliquable (mobile)
        
        **Priorité : Indispensable**
