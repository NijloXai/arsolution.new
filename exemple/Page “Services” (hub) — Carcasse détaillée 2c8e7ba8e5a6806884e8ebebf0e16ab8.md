# Page “Services” (hub) — Carcasse détaillée

### Rôle & objectifs

- **Rôle** : vue d’ensemble des prestations + orientation vers les sous-pages + conversion (devis).
- **Objectif SEO** : page “hub” qui **maillage** toutes les pages services (logique silo).
- **CTA principal** : “Demander un devis” (+ “Marchés publics : contact dédié”).

### SEO (cadrage)

- **URL** : `/services/`
- **H1** : “Nos services de rénovation intérieure & isolation — Strasbourg / Alsace”
- **Schema** : `ProfessionalService` + éventuellement liste `Service` (selon implémentation).

### Sections (ordre recommandé)

### 1) Hero “Services”

**Objectif** : comprendre l’offre en 5 secondes + pousser vers devis + accès MP.

- Contenu : titre + sous-titre (plâtrerie / isolation / peinture / finitions) + zone Strasbourg/Alsace + badges (RGE, décennale, RC Pro) + 2 CTA (Devis / Marchés publics).
    
    **Priorité : Indispensable**
    

### 2) Cartes “Tous nos services” (le cœur)

**Objectif** : scan rapide + clic vers pages détaillées.

- 4–6 cartes :
    - Plâtrerie & faux plafonds
    - Isolation thermique & phonique
    - Aménagement intérieur
    - Peinture & lissage
    - Enduit & finitions (option si tu veux garder séparé)
- Pour chaque carte : 1 phrase bénéfice + 3 puces “on fait” + lien “Détails” + micro-CTA “Devis [service]”.
    
    **Priorité : Indispensable**
    

### 3) Entrée “Marchés publics / propriétaires publics”

**Objectif** : mettre la priorité business en évidence depuis le hub services.

- Bloc court : “Vous êtes acheteur public / gestionnaire ? → méthode, justificatifs, références” + CTA vers page Marchés publics.
    
    **Priorité : Indispensable**
    

### 4) “Comment ça se passe ?” (process)

**Objectif** : rassurer sur organisation / planning / propreté.

- Étapes : Contact → Visite → Devis → Planification → Travaux → Réception.
    
    **Priorité : Recommandé**
    

### 5) Preuve par l’image (mini-portfolio par service)

**Objectif** : prouver au niveau “services” (avant même la page Réalisations).

- 3–6 projets, idéalement avec tags par service + CTA “Voir toutes les réalisations”.
    
    **Priorité : Recommandé**
    

### 6) “Pourquoi nous ?” (différenciation)

**Objectif** : arguments concrets (finitions, sérieux, RGE, garanties).

- 4–6 bullets max (pas de blabla).
    
    **Priorité : Recommandé**
    

### 7) FAQ courte “Services”

**Objectif** : lever freins communs (délais, propreté, devis, garanties, zone).

**Priorité : Optionnel** (si déjà bien traité ailleurs)

### 8) CTA final

**Objectif** : conversion (devis) + alternative MP.

**Priorité : Indispensable**
