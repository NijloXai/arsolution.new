# Page “À propos” — Carcasse détaillée

### Rôle & objectifs

- **Rôle** : humaniser + prouver la fiabilité (histoire, équipe, méthode, garanties) → lever les peurs “délais / propreté / sérieux” et pousser au contact.
- **Cibles** : **marchés publics / propriétaires publics** (priorité), puis pros/copro, puis particuliers.
- **CTA principal** : “Demander un devis” + CTA secondaire “Marchés publics : contact dédié”.

### SEO (cadrage)

- URL : `/a-propos/`
- H1 (ex) : “AR+SOLUTION — entreprise de rénovation intérieure & isolation à Strasbourg” (avec variation Alsace possible)

---

### Sections (ordre recommandé)

### 1) Hero “Qui nous sommes”

**Objectif** : confiance immédiate + ancrage local + preuve.

- Contenus attendus :
    - H1 + 1–2 lignes : métiers + zone (Strasbourg/Alsace)
    - Preuves visibles : **Certifié RGE**, décennale, RC Pro (logos)
    - 2 CTA : Devis / Marchés publics
    - Photo réelle (équipe ou chantier)
        
        **Priorité : Indispensable**
        

### 2) “Notre histoire” (depuis 2006)

**Objectif** : crédibilité + stabilité.

- Contenus :
    - Timeline courte : démarrage 2006 → équipe stable → élargissement services
    - 1 paragraphe “mission” : rénovation énergétique globale + finitions
        
        **Priorité : Indispensable**
        

### 3) “Ce que nous faisons” (rappel des services)

**Objectif** : récap ultra clair + renvoi vers pages services (maillage).

- Format : liste/mini-cartes (Plâtrerie, Isolation, Enduits, Peinture, Rénovation globale) + liens.
    
    **Priorité : Recommandé**
    

### 4) “Nos engagements” (valeurs opérationnelles)

**Objectif** : répondre aux freins majeurs : délais, propreté, transparence, qualité.

- 4–6 engagements max, formulations concrètes :
    - organisation / planning validé
    - chantier protégé + propreté
    - finitions soignées
    - devis clair et détaillé
    - communication simple / interlocuteur identifié (si vous le tenez)
        
        **Priorité : Indispensable**
        

### 5) “Notre méthode” (les étapes)

**Objectif** : transparence premium + rassurer les acheteurs publics/propriétaires publics.

- Étapes : Contact → Visite → Devis → Planification → Travaux → Réception
- Micro-texte : “délais discutés et adaptés selon chantier” (sans promesse risquée)
    
    **Priorité : Recommandé**
    

### 6) Bloc “Marchés publics / propriétaires publics”

**Objectif** : refléter ta priorité business directement sur À propos.

- Contenus attendus :
    - 3 points : conformité / organisation / références (renvoi portfolio filtré)
    - CTA : “Accéder à Marchés publics” + “Contact dédié”
    - Mention : justificatifs disponibles sur demande (RGE, assurances)
        
        **Priorité : Indispensable**
        

### 7) “Équipe & terrain” (incarnation)

**Objectif** : humaniser + rassurer “vrais pros, vraie équipe”.

- Contenus :
    - 1–2 photos équipe/dirigeant (réelles)
    - 3–5 bullets : stabilité, expérience, matériaux/techniques modernes, approche individuelle
        
        **Priorité : Recommandé**
        

### 8) “Garanties, assurances, infos légales”

**Objectif** : lever l’objection “documents officiels ?”.

- Contenus :
    - Logos + texte clair : RGE, décennale, RC Pro
    - Option : afficher l’assurance **APRIL** + n° de police (si assumé publiquement) ou “sur demande”
    - Liens : Mentions légales / Politique de confidentialité
        
        **Priorité : Indispensable**
        

### 9) Preuve “Avant/Après” + Avis (extraits)

**Objectif** : relier l’humain à la preuve.

- 3 projets + 2–3 avis (si dispo) + CTA “Voir toutes les réalisations”
    
    **Priorité : Recommandé**
    

### 10) CTA final

**Objectif** : conversion après rassurance.

- Double CTA : Devis / Marchés publics
    
    **Priorité : Indispensable**
