# Page service “Isolation thermique & phonique” — Carcasse détaillée

### Rôle & objectifs

- **Rôle** : page pilier SEO + conversion, et axe “rénovation énergétique globale” + RGE.
- **Objectif contenu** : page riche (souvent **≥ 800 mots**), pédagogique, structurée, avec mini-cas + FAQ.
- **CTA principal** : “Devis isolation” (+ “Marchés publics : contact dédié”).

### SEO (cadrage)

- **Slug (exemple)** : `/services/isolation-thermique-phonique-alsace/` (ou Strasbourg selon cible)
- **H1** : “Isolation thermique & phonique à Strasbourg / Alsace (certifié RGE)”
- **Schema** : `Service` + `FAQPage` (si FAQ) + `LocalBusiness`.

### Sections (ordre recommandé)

### 1) Hero (service + localisation + RGE + CTA)

**Objectif** : répondre à “faites-vous ça ici, êtes-vous RGE, comment je demande un devis ?”.

- Contenu : titre + sous-titre (thermique/phonique) + bénéfices (confort + économies) + badges RGE/décennale/RC Pro + CTA “Devis isolation” + CTA MP.
    
    **Priorité : Indispensable**
    

### 2) “Thermique vs phonique : quelle isolation pour quel besoin ?”

**Objectif** : clarifier vite et éviter les demandes floues.

- Contenu : 2 colonnes (Thermique / Phonique), exemples de situations (appartement centre-ville, bureaux, parties communes…).
    
    **Priorité : Indispensable**
    

### 3) Où intervient-on ? (murs, cloisons, plafonds…)

**Objectif** : rendre la prestation tangible.

- Contenu : liste “zones de travaux” + renvoi vers plâtrerie si cloisons/placo impliqués (maillage interne).
    
    **Priorité : Recommandé**
    

### 4) Bénéfices concrets

**Objectif** : transformation attendue (confort, calme, factures).

- Contenu : 4–6 bullets maximum, orientés résultats.
    
    **Priorité : Recommandé**
    

### 5) “Matériaux & solutions” (pédagogie simple)

**Objectif** : rassurer sans jargon, montrer expertise.

- Contenu : 3–5 blocs (matériau / quand on l’utilise / bénéfice)
- Note : on peut citer des marques **uniquement si souhaité** (sinon rester générique).
    
    **Priorité : Recommandé**
    

### 6) “Notre méthode” (organisation & qualité)

**Objectif** : fiabilité (délais, propreté, étapes).

- Étapes : visite → devis → planification → pose → finitions → réception.
    
    **Priorité : Recommandé**
    

### 7) Bloc “RGE & aides” (informatif uniquement)

**Objectif** : répondre à la question récurrente sans promettre d’accompagnement.

- Contenu :
    - “Pourquoi le RGE compte”
    - MaPrimeRénov’ / CEE / éco-PTZ (aperçu)
    - Phrase claire : “Nous informons sur les principes ; les démarches se font via les organismes/plateformes dédiés.”
        
        **Priorité : Indispensable** (vu la récurrence de la question RGE/aides)
        

### 8) Mini études de cas (1–2) localisées

**Objectif** : preuve + SEO local + crédibilité.

- Format : contexte / contrainte / solution / résultat + 2–4 photos.
- Tag “Secteur public” si applicable.
    
    **Priorité : Indispensable**
    

### 9) FAQ isolation (6–8 questions)

**Objectif** : lever freins (budget, durée, poussière, choix thermique/phonique, RGE, zone, etc.).

- Peut être balisée `FAQPage`.
    
    **Priorité : Indispensable**
    

### 10) CTA final (conversion)

**Objectif** : “ok j’ai compris, je contacte”.

- Contenu : rappel bénéfice + CTA “Devis isolation” + alternative MP + tel cliquable (mobile).
    
    **Priorité : Indispensable**
