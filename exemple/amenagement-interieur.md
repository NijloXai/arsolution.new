# Page service “Aménagement intérieur” — Carcasse détaillée

### Rôle & objectifs

- **Rôle** : montrer la **polyvalence** (reconfiguration, création d’espaces) + prouver par l’image + convertir.
- **Différenciation** : “interlocuteur unique” possible car vous gérez **plâtrerie / isolation / peinture** sur un même projet.
- **CTA** : “Devis aménagement intérieur” + “Marchés publics : contact dédié”.

### SEO (cadrage)

- Slug (ex) : `/services/amenagement-interieur-strasbourg/`
- H1 (ex) : “Aménagement intérieur à Strasbourg / Alsace”

### Sections (ordre recommandé)

### 1) Hero (aménagement + localisation + preuves + CTA)

**Objectif** : “on peut transformer mon espace ? où ? comment je contacte ?”

- Titre + sous-titre + badges (RGE/assurances) + 2 CTA (Devis / MP).
    
    **Priorité : Indispensable**
    

### 2) “Types de projets” (liste concrète)

**Objectif** : rendre l’offre tangible, éviter le flou.

- Liste (cartes) :
    - Redistribution de pièces / création de cloisons
    - Création de nouvelles pièces / dressings
    - Combles / caves / optimisation de volumes
    - Bureaux / locaux professionnels / parties communes (si vous l’assumez)
        
        **Priorité : Indispensable**
        

### 3) Entrées par cible (dont Public en 1er)

**Objectif** : coller à ta priorité “marchés publics / propriétaires publics”.

- 3 blocs :
    1. **Propriétaires publics / marchés publics** (contraintes, conformité, contact dédié)
    2. Pros/copro (continuité d’activité, nuisances)
    3. Particuliers (confort, esthétique)
        
        **Priorité : Recommandé**
        

### 4) Bloc “Inspiration” (avant/après)

**Objectif** : preuve visuelle (pilier du site).

- Galerie 6–10 visuels (ou 3–6 projets) + tags + CTA vers Réalisations filtrées “Aménagement”.
    
    **Priorité : Indispensable**
    

### 5) “Interlocuteur unique : plâtrerie + isolation + peinture”

**Objectif** : argument business simple : moins de coordination, plus de maîtrise.

- Contenu : 3–5 bullets “ce que ça change” + liens vers services associés.
    
    **Priorité : Indispensable**
    

### 6) “Notre méthode” (étapes & organisation)

**Objectif** : rassurer sur délais/propreté/communication.

- Étapes : contact → visite → devis → planification → travaux → réception.
    
    **Priorité : Recommandé**
    

### 7) Mini-études de cas (1–2)

**Objectif** : crédibilité + SEO local + conversion.

- Format : contexte / contrainte / solution / résultat + ville/quartier.
    
    **Priorité : Recommandé**
    

### 8) Bloc “Marchés publics : conformité & pièces”

**Objectif** : enlever le frein administratif (docs sur demande).

- RGE + assurances + CTA “Contact MP”.
    
    **Priorité : Recommandé**
    

### 9) FAQ Aménagement (6–8)

**Objectif** : lever les freins (délais, nuisances, coordination, devis).

**Priorité : Indispensable**

### 10) CTA final

**Objectif** : convertir.

**Priorité : Indispensable**
