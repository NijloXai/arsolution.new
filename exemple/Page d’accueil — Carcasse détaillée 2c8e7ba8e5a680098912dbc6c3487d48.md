# Page d’accueil — Carcasse détaillée

---

### Rôle & objectif

- **Rôle** : créer une **confiance immédiate** (“Qui / Quoi / Où / Pourquoi vous ?”) + pousser vers le **CTA devis** et vers le chemin **Marchés publics**.
- **Objectif conversion** : demandes de devis/contact, avec friction minimale (mobile-first, CTA sticky, 3–5 champs).
- **Preuve centrale** : **portfolio avant/après** + avis + certifications/assurances.

---

## 0) Éléments persistants (UX)

### Header sticky

- Logo + menu (5–7 entrées max) + CTA “Demander un devis” + téléphone cliquable.
- **Accès direct “Marchés publics”** visible au menu (priorité business).

### Mobile

- Bouton **tap-to-call** / CTA flottant ; formulaires adaptés (clavier tel).

---

## 1) Hero “Qui / Quoi / Où + preuve + 2 chemins”

**Objectif** : répondre en 5 secondes + orienter vers **Devis** ET **Marchés publics**.

**Contenus attendus**

- H1 (structure) : *métier + bénéfice + localisation* (ex : rénovation intérieure / isolation / finitions à Strasbourg-Alsace)
- Sous-titre : “plâtrerie / isolation / enduits / peinture” + “interlocuteur unique” (si tu assumes cette promesse).
- **Bande “preuves”** (icônes/logos) : **Certifié RGE**, décennale, RC Pro.
- CTA principal : “Demander un devis”
- CTA secondaire (très visible) : “Marchés publics : contact dédié” (renvoie vers la page hub MP)
- Visuel : photo réelle chantier/équipe (pas banque d’images).
    
    **Objections traitées**
    
- “Êtes-vous fiables / assurés / certifiés ?”
- “Intervenez-vous bien en Alsace / Strasbourg ?”
- “Faites-vous le lot finitions + isolation ?”
    
    **Priorité : Indispensable**
    

---

## 2) Barre “confiance immédiate” (3–5 preuves chiffrées)

**Objectif** : renforcer la crédibilité sans bla-bla.

**Formats possibles**

- 3 à 5 items : “RGE”, “Décennale”, “Depuis 2006”, “15–20+ projets”, “Strasbourg & Alsace”.
    
    **Priorité : Indispensable**
    

---

## 3) Entrées par profils (dont “Marchés publics” en 1er)

**Objectif** : aider chaque visiteur à se reconnaître + aller au bon contenu.

**Blocs (cartes)**

1. **Marchés publics / propriétaires publics** → page MP (hub)
2. Copro / bureaux / gestionnaires → références + contact
3. Particuliers → services + réalisations
    
    **CTA** : “Voir le parcours” / “Nous consulter”
    
    **Priorité : Recommandé (très utile vu ton pivot cible)**
    

---

## 4) Aperçu Services (cartes)

**Objectif** : exposer l’offre sans surcharger la home + nourrir le maillage vers pages SEO service.

**Contenus attendus**

- 4–6 cartes : Plâtrerie/faux plafonds, Isolation thermique/phonique, Aménagement intérieur, Peinture/lissage, Enduit & finitions (option).
- 1 phrase bénéfice + lien “En savoir plus” + mini-CTA “Devis [service]”
    
    **Priorité : Indispensable**
    

---

## 5) Portfolio preview “preuve par l’image”

**Objectif** : argument #1 du site : montrer avant/après + local + qualité finitions.

**Contenus attendus**

- 3–6 projets mis en avant (les meilleurs)
- Pour chaque : type travaux + ville/quartier + 1 phrase résultat
- Format : avant/après (slider ou 2 vignettes)
- CTA : “Voir toutes les réalisations”
    
    **Priorité : Indispensable**
    

---

## 6) “Pourquoi AR+SOLUTION ?” (différenciation concrète)

**Objectif** : traduire le positionnement “fiable + finitions + transparence” en bénéfices.

**Contenus attendus (6 points max)**

- Respect planning (formulation prudente)
- Propreté / protection chantier
- Finitions soignées (enduits, murs lisses, peinture)
- Devis clair et détaillé
- Certifié RGE + assurances
- Ancrage local Strasbourg/Alsace
    
    **Priorité : Indispensable**
    

---

## 7) “Méthode / étapes” (transparence premium)

**Objectif** : rassurer sur l’organisation, point critique pour publics et propriétaires.

**Contenus attendus**

- 5 étapes : Contact → Visite → Devis → Planification → Travaux → Réception
- Mini engagements : communication, propreté, photos d’avancement (si vous le faites, sinon ne pas promettre)
    
    **Priorité : Recommandé**
    

---

## 8) Bloc dédié “Marchés publics : conformité & contact”

**Objectif** : faire de la home un vrai levier pour ta cible prioritaire.

**Contenus attendus**

- 3 sous-blocs :
    1. **Références** (secteur public si dispo / ou “projets comparables”)
    2. **Justificatifs** : RGE + assurances (bouton “Demander les documents”)
    3. **Contact dédié** (email/tel + mini-form)
        
        **Priorité : Indispensable (vu ta stratégie)**
        

---

## 9) Avis / preuve sociale (Google)

**Objectif** : renforcer la confiance, surtout pour visiteurs non “marché public”.

**Contenus attendus**

- Widget note + 2–3 avis (si vous avez assez de volume)
- CTA : “Voir tous les avis”
    
    **Priorité : Recommandé** (selon disponibilité réelle des avis)
    

---

## 10) Zone d’intervention

**Objectif** : signal SEO local + rassurer “vous venez bien chez nous”.

**Contenus attendus**

- “Basé à Strasbourg — interventions Alsace / environs” + carte ou liste de communes
    
    **Priorité : Recommandé**
    

---

## 11) Mini-FAQ (4–6 questions)

**Objectif** : lever les freins majeurs (délais, propreté, garanties, RGE, devis).

**Important** : sur “aides”, rester **informatif uniquement**.

**Priorité : Recommandé**

---

## 12) CTA final “Demander un devis”

**Objectif** : conversion sans friction (et alternative “marchés publics”).

**Contenus attendus**

- Rappel promesse (1–2 lignes)
- Formulaire court (3–5 champs) + tel/email + RGPD
- Double CTA : “Demander un devis” + “Marchés publics : contact dédié”
    
    **Priorité : Indispensable**
    

---

## Notes de cohérence (à appliquer partout sur la home)

- Un seul H1, Title/Meta uniques avec **service + localisation**.
- Photos réelles, compressées (WebP <150 Ko, lazy-load), perf mobile <3s.
- CTA répétés + parcours en **3 clics max**.
